# Original QuickCheck vector runtime

QuickCheck2.16.0.0 Gen.hs has vectorOf=Control.Monad.replicateM; its Applicative
uses (<*>)=ap, and Monad splits each bind. The retained GHC9.12.2 interface dump
of GHC.Internal.Control.Monad independently shows replicateM's actual recursive
liftA2(:)/pure[] unfolding. This is generated compiler evidence, not a replacement
Haskell implementation. The oracle calls the original package unchanged.

180 records cross six machine-Int seed witnesses (including both bounds), three
sizes and ten counts(-1,0,1,2,3,31,32,33,1024,100000). Every small vector is retained
completely; explicit selected positions retain exact values for100000-element
vectors. Original native expectations are not generated by Kotlin.

Ten native demand stages use NOINLINE test callbacks and IORef counters to
observe actual lazy element-thunk evaluation: measuring100000-element length
runs no callback, selected indices run only the selected callbacks, repeated
reads share results, synchronous exceptions are shared, and successful Nothing
values are shared. unsafePerformIO belongs only to the dev oracle instrumentation;
it is never a conversion dependency. Exceptions/demand observations cover finite
known spines and deterministic callbacks; asynchronous cancellation and cyclic
self-demand are not a general GHC runtime contract.

Kotlin's old vector built100000 nested generators eagerly and also evaluated all
elements while constructing the list. The new finite read-only memoized List
allocates only demanded cells/seed prefixes; it preserves seed splitting,
repeated-value/exception sharing, nullable values, index bounds and per-run
isolation. All nineteen original AST generator replays remain regression inputs.
