# Original HTML table parser observer

Builds the complete original pinned Pandoc library. `prepare.py` copies all 2,888
tracked files and verifies that implementation, tests, data and notices remain
byte-exact. Only Cabal visibility declarations change: HTML Parsing, Types,
TagCategories and Table are exposed to the observer. The original checkout is
untouched. No parser implementation is extracted or replaced.

```
python3 tools/haskell-html-table-reference/prepare.py --directory /private/tmp/kotdoc-html-table-original
cabal build html-table-reference --project-file=/private/tmp/kotdoc-html-table-original/cabal.project --builddir=/private/tmp/kotdoc-html-table-build
```

Use GHC 9.12.2 and the pinned Cabal environment. Freeze dependencies and repeat
the build before capture. The documented library-only -O0 setting is retained;
the observer/dependencies use -O2. All original HTML assertions/property remain
registered, with a separate helper serialization check and a module-renamed copy
of the otherwise byte-exact original test helper.

The production pTable accepts a caller-supplied cell/caption parser. The oracle
supplies text, arbitrary original AST payloads, nested-table parsers and failing
or stateful callbacks. Kotlin supplies the same caller configuration; all table
expectations are generated by the original pTable. Original HTML fixture table
spans and all original Native documents are retained at this module boundary.
This is not a claim that the complete HTML reader is ported. Normal cases compare
full AST JSON and Show; deep table cases compare complete AST Show without
exercising the separate general AST JSON codec. SafeRead and the original simple-
cell query are also observed directly.

Stateful callbacks also mutate the original PandocMonad CommonState, independently
of Parsec's user state. Captures distinguish retained external effects from
restored input/user state under lookahead, speculative headers and failing tables.
Original HTML, HTML4 and HTML5 table fixtures are read without newline rewriting.
