# Remaining Builder constructors and normalization

This checkpoint maps 49 Builder-owned exports and Definition.nullAttr, the private
quoted helper, and 19 containers Seq dependency helpers in acceptance-matrix.json.
It does not close all 140 module exports or 350 source instances. Individual
instance members require a separate expansion; generic Many/count-derived
classes, Data.Version and JSON filter gates remain open.

The executable imports the actual pinned Builder, Definition and Data.Sequence.
17,630 finite observations preserve values and noncommutative foldMap grouping,
including complete split trees, text packing, all Inline/Block constructors,
boundary indices, and the original module example. 270 separate observations
exercise root/list/tuple demand, partial finger trees and later forced failures,
shared length 2^40/Long endpoints, deep normalization and constructor nesting.
Expected responses are unmodified original output, not generated by Kotlin.
The unchanged original Figure property contributes 305 further independent cases.

PandocBuilders exposes callbacks and GenericNode/GenericList/GenericTuple carriers
for source WHNF behavior. BuilderInlines/BuilderBlocks retain actual Many trees.
Finite strict AST bridges are conveniences and do not represent every undefined
Haskell field. ManySplit preserves weighted branch shapes and source lazy digit
views. Many iteration schedules child thunks instead of fetching siblings;
Single measures its cell only when size is demanded. Existing Long constructors
remain available. Five preserved legacy reproductions explain the four Builder
body delegations; default orderedList retains its delegation to orderedListWith.
No arbitrary Haskell heap/bottom equivalence or unbounded JVM list claim is made.

historical/ retains accepted Builder/Many bytes and prior Many/metadata/table
manifests. integration-manifest.json records old-to-new current bindings and
exact patches separately. Historical native expectations and prior manifests
are not rewritten. Current integrity manifests are refreshed only for the
explicit production dependency hashes; their observation payloads are unchanged.
